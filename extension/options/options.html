Beryy settings

Connect NVIDIA NIM, Google AI Studio, Groq, OpenRouter, local Ollama, or an OpenAI-compatible endpoint. Everything stays in this Chrome profile.

Model provider

Keys and model choices are saved separately for each provider. Switch providers here or from the side panel. Any compatible /chat/completions endpoint also works. Local Ollama models need no API key. Rate limits and temporary provider outages are retried automatically with backoff.

Google API rate limits
Beryy waits before sending a request that would exceed these limits. TPM reserves the estimated prompt plus max output tokens. Change these values to match your Google project quota.

Ollama local settings

Native mode uses /api/chat and applies every option below. The OpenAI-compatible mode uses /v1 and only applies the shared temperature and output-token settings. Lower num_ctx, GPU layers, batch size, and threads to reduce memory; keep the model loaded with keep_alive to avoid reload delays.

Permissions

Beryy asks before it reads, clicks, types, navigates, or runs JavaScript. Read-only mode is the safest default for unfamiliar sites.

Privacy and pacing

Beryy blocks a bundled list of known ad, analytics, and social trackers. Add a site here if blocking breaks it. This list is separate from action permissions.

Custom instructions
