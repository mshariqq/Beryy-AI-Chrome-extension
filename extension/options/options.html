Beryy settings

Connect NVIDIA NIM, Google AI Studio, Groq, or OpenRouter. Everything stays in this Chrome profile.

Model provider

Keys and model choices are saved separately for each provider. Switch providers here or from the side panel. Any compatible /chat/completions endpoint also works. Rate limits and temporary provider outages are retried automatically with backoff.

Google API rate limits
Beryy waits before sending a request that would exceed these limits. TPM reserves the estimated prompt plus max output tokens. Change these values to match your Google project quota.

Permissions

Beryy asks before it reads, clicks, types, navigates, or runs JavaScript. Read-only mode is the safest default for unfamiliar sites.

Privacy and pacing

Beryy blocks a bundled list of known ad, analytics, and social trackers. Add a site here if blocking breaks it. This list is separate from action permissions.

Custom instructions

Beryy is an independent experiment. It is not affiliated with Anthropic or Claude. Use it only on sites and accounts you are allowed to automate.
